## 三、ETL 规则（P2-2b 让 CodeBuddy 实现的内容概要）

1. 薪资解析：`10-15K` → (10, 15, 月)；`20-30K·13薪` → (20, 30, 月, 13 薪)；`6-8千` → (6, 8, 千)；`120-150元/天` → 日薪单列，不混入月薪统计；
2. 经验规整：`3-5年→(3,5)`、`经验不限→(0,0)`、`在校/应届→(0,0)`、`5年及以上→(5,99)`；
3. 学历规整：本科/大专/硕士/学历不限 → 枚举值；
4. 去重键：`公司+职位名+城市`；
5. 脱敏（`etl\mask.py`）：岗位描述中出现的手机号/邮箱/微信号一律替换为 `[CONTACT]`；
6. 产出：`data\cleaned\jobs_cleaned.csv` → 灌入 MySQL `jobs` 表与 DuckDB `job_feature` 表。
