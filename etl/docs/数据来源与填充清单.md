数据分四类，含义严格区分：

| 类别 | 含义 | 能否核对 |
|---|---|---|
| **A 真实外部数据** | 从官网/公开数据集抓来的真实世界数据 | 能，逐条点开原文链接或对原始 CSV |
| **B 真实派生** | 用 A 类数据算出来的结果 | 能，按同一口径可复算 |
| **C 模拟生成** | 虚构数据（隐私/权限拿不到真实数据） | 不能，纯演示用 |
| **D 系统运行产生** | 系统/用户操作留下的记录 | 能，是实际运行轨迹 |

## 5. 主动留空的字段（补了就是造假）

| 表.字段 | 空着的原因 |
|---|---|
| `招考公告` 的学历/学位/专业/政治面貌等要求 | 重庆事业单位公告把**分项要求写在附件岗位表里**，正文只有泛述。旧版抽取器把同一段资格审查流程话塞进 3 个字段，看着满、语义全错，本轮已清掉 48 个错值。现在抽不到就 NULL，前端显示「公告未单独说明，具体以附件岗位表为准」，正文全文可读可自查 |
| `学校通知.链接` | 通知标题是公开赛制的通用表述，没有对应原文链接。填假链接 = 点进去是死链，宁可不填 |
| `简历技能证书.获得时间`（技能类 50 行） | 技能没有「获得时间」，只有证书才有 |
| `学生扩展信息.六级分数`（66%） | 不是所有学生都考六级，空 = 未考 |
| `抓取运行日志.错误` / `工作流运行.错误` | 只在失败时才有内容 |
| `对话会话.摘要` | 只在会话超过 12 轮时生成 |
| `知识库文档.文件名` / `来源地址` | 文本入库没有文件名，属正常 |
