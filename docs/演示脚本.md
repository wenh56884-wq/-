# 5 分钟演示脚本与台词

> 演示环境（两条命令）：
> ```powershell
> # 1) 构建前端（首次或改过 src 时执行）
> powershell -File scripts\build_web.ps1
> # 2) 起服务（后端同时托管静态站）
> .\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
> # 3) 浏览器打开
> http://127.0.0.1:8000
> ```
> 备份手段：整段演示建议提前录屏；`docs\VERIFY.md` 里有同一批数字，可作为截图外的第二证据。
> 演示数据：班级 `AI2201`、学生 `AI2022001 陈鹏`、学期 `2025-2026-2`。

## 0:00 — 开场一句话定位

**操作**：浏览器打开 `http://127.0.0.1:8000`，停 2 秒让大家看清登录页，再登录。

**屏幕上**：登录页（身份单选：教师 / 学生）。

**台词**（≤3 句）
> 这个系统叫启航，解决两件事：让辅导员提前发现被学业拖垮的学生，让学生看清自己跟岗位差在哪。
> 全站所有数字都由确定性引擎算出，AI 只负责把结论说成人话。
> 我先从教师端开始。

**操作**：滚到"岗位推荐"，`top_n` 保持 5，念第一条。

**屏幕上**

1  大数据分析师   湖北创佑科兴信息科技有限公司   上海   8000-12000   匹配度 0.7742

**台词**

> 0.7742 这个分数是专业、成绩、技能、兴趣四项加权得到的，不含任何随机数。

## 4:20 — 技术亮点（30 秒）：为什么数字可信 + 为什么不能越权

**操作**：切回预先准备好的标签——用学生 token 直接请求教师接口（或现场用 curl/apifox 演示）。

**屏幕上**：请求 `GET /teacher/warnings` 返回 **HTTP 403**，页面弹出"没有权限访问该数据，请重新登录"并跳回登录页。

**台词**
> 最后 30 秒说两件事。第一，数字为什么可信：引擎算、Critic 查，模型改不了一个数；改不动就降级，宁可不给数也不给错数。
> 第二，为什么不能越权：学号不靠前端传、只认登录态，学生直接打教师接口立刻 403 并被登出，且每次请求都写审计日志。

# 附：三类兜底方案

## 1. API 断网 / 服务起不来

| 现象 | 处置 |
|---|---|
| 白屏、`502` 或 `ERR_CONNECTION_REFUSED` | 切**录屏**（同一套画面提前录好） |
| 只想证明接口层正常 | 跑 `powershell -File scripts\smoke_test.ps1`，贴 12 项 PASS 的终端输出 |
| 只想证明数据层正常 | 跑 `python scripts\gen_verify_report.py`，贴 `docs\VERIFY.md` 第 2/3/4 节 |

**标准话术**："现场服务依赖内网 MySQL，这部分我用同一版代码的录屏补上；回归脚本我现在可以现场跑，跑的是同一套数据。"

## 2. 数据库连不上（MySQL / DuckDB）

| 现象 | 处置 |
|---|---|
| `/health` 里 `db=down` 或 `duckdb=down` | 立即切到**已导出的结果图**（看板、归因、推荐列表各一张，附本次真实数值） |
| 想说明不是代码问题 | 指 `/health` 的降级行为：`status=degraded`，说明健康检测是真检测不是摆设 |

**标准话术**："连不上属于环境问题，我带了同一批数据的导出结果；健康检测接口本身也是真检测，`db=down` 时会如实报 degraded。"

## 3. 被问到没做的功能

统一口径：**先定性 → 再说二期计划 → 最后给现在的替代方案**，不要临场发挥。

| 可能的提问 | 标准回答 |
|---|---|
| "为什么没有深度学习 / 协同过滤推荐？" | "现在用的是可解释的规则打分（含冷启动分支），二期会加协同过滤并按 `final = 0.7*A + 0.3*B` 融合。规则版的好处是每条推荐都能说清命中什么、缺什么。" |
| "为什么用 DuckDB 不用 ClickHouse？" | "单机交付形态下 DuckDB 等价可用且零运维；存储层做了 `Store` 抽象（`DuckDBStore` / `ClickHouseStore`），二期换引擎不改引擎层代码。" |
| "为什么班级只有 1 个人？" | "这是 mock 数据生成时每人一个班级名导致的；预警、画像、推荐链路按班级维度都跑通了，重新造数把学生归到固定班级即可看到多人视图。" |
| "为什么不显示灰档（数据不足）？" | "真实库里目前没有缺考勤的学生，灰档只在单测里验过；演示前可以构造几名无考勤记录的学生，看板会显示『数据不足』而不是绿色。" |
| "大模型到底做了什么？" | "只做表达：`plan` 选工具、`draft` 组织语言、`critic` 回查数字，数值一律引用引擎输出，查不过就降级成不含数字的安全话术。" |
| "大一新生为什么必须先选目标？" | "大一还没有明确方向，先选考公/考研/考编/就业，系统再用确定性规则生成四年路径；大二/大三不强制补选，直接给探索型规划。" |
