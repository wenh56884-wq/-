**Bug 1：`/pet/*` 请求未携带鉴权头（401）**

- **现象**：学生登录后进入首页，`/pet/personality`、`/pet/memories`、`/pet/state` 三个请求均未携带 `Authorization: Bearer <token>` 头，导致后端返回 401
- **证据**：`verify_public_twin.py` 捕获 `auth=no`；带 token 的 curl 请求均返回 200
- **复现步骤**：
  1. 访问 `http://101.34.254.115/`
  2. 以学生（大四）AI20230001 / 123456h 登录
  3. 进入 `/student` 首页

  5. 观察 `/pet/personality`、`/pet/memories`、`/pet/state` 三个请求
  6. 请求 Header 中无 `Authorization` 字段，响应 401
- **建议**：检查 `usePet.js` 中 axios 请求是否经由 `web/src/api/http.js` 共享实例，确认请求拦截器已正确注入 `localStorage` 中的 `qh_token`；或在 `usePet.js` 中显式添加鉴权头
